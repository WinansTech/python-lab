# python-lab

Central catchall for my Python exercises, experiments, and small projects.

## About

A personal sandbox for learning, prototyping, and tinkering with Python. Nothing here is production-grade — just a place to try things out, throw things together, keep notes, and collect useful snippets over time.

## Structure

python-lab/
├── exercises/      # Small practice problems and challenges
├── experiments/    # Exploratory scripts and prototypes
├── snippets/       # Reusable bits of code
└── notes/          # Markdown notes and write-ups

> Feel free to organize things however works best for you.

## Requirements
- Python 3.10+
- Individual experiments may list their own dependencies
